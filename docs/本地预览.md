# 本地预览

本项目用 Mintlify 渲染中文站，配置文件为 `translated/docs.json`。

## 启动命令

必须在 **`translated/` 目录**下启动（docs.json 在这里）：

```bash
cd translated && npx -y mint@latest dev
```

启动后打开浏览器访问 **http://localhost:3000**。

> 从仓库根目录一步启动：
>
> ```bash
> cd /Users/ianyin/idea-stud-pro/modelcontextprotocol-zh/translated && npx -y mint@latest dev
> ```

## 说明

- **首次启动**会拉取 `mint` 包并构建，需等十几到几十秒；日志出现 `Local: http://localhost:3000` 即就绪。
- **热重载**：修改 `.mdx` 或 `docs.json` 后自动刷新；若未生效，`Ctrl+C` 停掉重跑。
- **换端口**：`npx -y mint@latest dev --port 3333`
- **停止**：在运行终端按 `Ctrl+C`。
- **版本排查**：`npx mint@latest --version`；如遇兼容问题可固定版本 `npx mint@<版本号> dev`。

## 目录约定

- 页面源文件：`translated/**/*.mdx`
- 导航与站点配置：`translated/docs.json`
- 翻译进度表：`docs/plan.md`
