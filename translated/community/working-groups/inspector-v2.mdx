工作组

## 使命陈述

Inspector V2 工作组正在构建 Inspector V2——一个从头重新设计、以可维护性和可靠性为目标的全新基于 Web 的 MCP inspector。本群组交付一个共享的 Inspector Core 架构，在 Web、CLI 和 TUI 实现之间最大化代码复用，并配备一套全面的测试装置。这项工作需要跨维护者的协作，因为它横跨 UI、协议工具和测试基础设施，而这些今天没有任何单个维护者拥有。

## 范围

### 范围内

- `modelcontextprotocol/inspector` 仓库，包括：
- **Inspector Core** —— 一个全新的共享代码架构，为所有 Inspector 前端提供通用的 MCP 和协议接口。
- **Web Inspector UI** —— 基于 Mantine 和 TypeScript 构建的浏览器版 inspector。
- **CLI Inspector** —— 共享 Inspector Core 的命令行界面。
- **TUI Inspector** —— 共享 Inspector Core 的终端 UI。
- **测试装置** —— 跨所有 Inspector 表面的共享测试框架、fixture 和集成测试。
- 将 `main` 上现有的 Inspector 弃用并迁移到 `v1.x` 维护分支。
- 一旦 MCP TypeScript SDK V2 可用，即在 Inspector Core 内采用它。

### 范围外

- 核心 MCP 规范。
- MCP SDK 维护（TypeScript、Python 或任何其他语言 SDK）。
- MCP 服务器实现。

### 相关群组

- **SDK 工作组** —— Inspector Core 消费 TypeScript SDK；SDK V2 的采用需要协调。
- **MCP Apps 工作组** —— 围绕客户端/应用工效学和检查工作流的共享表面。
- **Auth 工作组** —— Inspector 在连接到受保护服务器时所使用的认证流程。
- **Registry 工作组** —— Inspector 向用户呈现的发现和元数据表面。

### 成功标准

1. **Q1 结束时** —— Web UI 完成，"哑"组件已接入真实的 MCP/Inspector Core 接口。
2. **Q1 结束时** —— Inspector Core 架构定稿。
3. **Q2 结束时** —— Inspector Core 合并到 `v2/main`，并与 Web UI 端到端工作。
4. **Q2 结束时** —— CLI 和 TUI Inspector 合并到 `v2/main`，并与 Inspector Core 端到端工作。
5. **Q2 结束时** —— `main` 上现有的 Inspector 迁移到 `v1.x` 分支并正式弃用。
6. **Q2 结束时** —— 新的 Inspector 家族（Web、CLI、TUI）发布并正式可用。
7. **Q3 结束时** —— Inspector Core 运行在 MCP TypeScript SDK V2 上（受 TypeScript SDK 工作组的交付时间表制约）。
