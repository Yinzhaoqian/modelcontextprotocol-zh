# 本地预览

本项目用 **Astro Starlight** 渲染中文站，工程在 `web/`。内容由 `translated/` 经迁移脚本生成，因此预览分两步：先生成内容，再启动开发服务器。

## 环境要求

- **Node ≥ 22.12**（Astro 7 要求）
- **Python 3**（运行迁移脚本，仅用标准库）

> 用 nvm 切换 Node：`nvm install 22 && nvm use 22`。

## 启动步骤

```bash
# 1. 生成 Starlight 内容（translated/ -> web/）
python scripts/migrate_mintlify_to_starlight.py

# 2. 安装依赖（首次）并启动开发服务器
cd web && npm install && npm run dev
```

启动后打开浏览器访问 **http://localhost:4321**。

## 常用命令

在 `web/` 目录下：

| 命令 | 说明 |
|------|------|
| `npm run dev` | 开发服务器（热重载），默认 4321 端口 |
| `npm run build` | 构建静态产物到 `web/dist/` |
| `npm run preview` | 本地预览构建产物 |
| `npm run dev -- --host 127.0.0.1` | 绑定 IPv4（某些环境 localhost 只解析到 IPv6 时用）|
| `npm run dev -- --port 3333` | 换端口 |

## 说明

- **改了 `translated/` 之后**：需要重新运行迁移脚本，`web/` 下的内容才会更新（`web/src/content/docs/**` 与 `public/` 下的图片均为生成物，不入库）。
- **改了 `web/` 脚手架**（`astro.config.mjs`、`src/components/**`、首页 `src/content/docs/index.mdx`）：这些是手写文件，直接生效，无需跑迁移脚本。
- **mermaid**：运行时从 CDN 加载并客户端渲染，跟随明暗主题。
- **停止**：在运行终端按 `Ctrl+C`。

## 目录约定

- 中文真源：`translated/**/*.mdx` + `translated/docs.json`
- Starlight 工程：`web/`
- 迁移脚本：`scripts/migrate_mintlify_to_starlight.py`
- 翻译进度表：`docs/plan.md`
- 部署说明：`docs/部署.md`
