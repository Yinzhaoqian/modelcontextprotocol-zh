## 群组类型

**工作组**

## 使命陈述

文件上传工作组的存在是为了定义 MCP 工具和征询请求如何声明文件输入，从而使宿主能够呈现原生文件选择器并将用户选定的文件内容传递给服务器。如今，需要从用户处获取文件的服务器不得不诉诸文字说明，要求提供 base64 字符串或本地路径，这产生了不一致的用户体验，并把编码细节推给终端用户。本工作组将规定一种最小化的、schema 层的机制来声明文件输入，以及投递它们的线路格式，以 [SEP-2356](https://github.com/modelcontextprotocol/modelcontextprotocol/pull/2356) 为锚点。

## 范围

### 范围内

- **规范工作**：定义工具输入 schema 和征询请求 schema 上声明式文件输入描述符、文件内容的线路编码，以及宿主侧处理要求的 SEP。
- **参考实现**：面向 `FileInputDescriptor`、data URI 编码的 SDK 类型和辅助工具，以及一个演示选择器调用和值替换的示例宿主流程。
- **跨领域关切**：在嵌入式 UI 表面呈现其自身文件选择器之处与 MCP Apps 工作组协调，并就宿主侧验证要求与 Security 工作组协调。
- **文档**：涵盖文件输入声明的规范章节，以及面向当前使用临时 base64 说明的服务器的迁移指南。

### 范围外

- 服务器到客户端的文件投递，这已由资源和 `BlobResourceContents` 涵盖。
- 对传输层或会话模型的更改。

本工作组可以在其设计工作中评估诸如流式传输、分块传输或预签名上传 URL 之类的方法；这些是落地于初始 SEP 还是后续 SEP，属于 WG 决策而非章程约束。

### 相关群组

- **MCP Apps 工作组** —— 嵌入式应用 UI 可能呈现其自身的文件选择器；描述符格式应在该上下文中可复用。
- **Security 工作组** —— 针对用户提供文件内容的宿主侧验证要求（该 SEP 就一般上传卫生引用了 [OWASP ASVS V5](https://owasp.org/www-project-application-security-verification-standard/)）。
- **工具标注 IG** —— 文件输入描述符是一种输入参数元数据，应与更广泛的标注分类法保持一致。
