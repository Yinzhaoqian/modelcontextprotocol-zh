## 概述

本条款（"条款"）规范你对官方 MCP 注册表（托管于 [https://registry.modelcontextprotocol.io/](https://registry.modelcontextprotocol.io/) 或其后继位置的服务，"注册表"）的访问和使用，包括对 MCP 服务器的提交或发布，对 MCP 服务器或关于此类服务器及/或其开发者的数据的引用（"注册表数据"），以及相关行为。注册表旨在成为由社区成员开发的 MCP 服务器的集中式仓库，以便 AI 应用轻松访问。

本条款受美国加利福尼亚州法律管辖。

## 面向所有用户

1. 无担保。注册表按"现状"提供，不附带任何形式的担保。这意味着我们不保证注册表、注册表中包含的服务器或注册表数据的准确性、完整性、安全性、持久性或可用性。简而言之，我们对任何 MCP 服务器或注册表数据也不承担责任，我们强烈建议你在决定是否使用某个 MCP 服务器之前，先评估它及其对你预期用例的适用性。

2. 访问和使用要求。要访问或使用注册表，你必须：
   1. 年满 18 周岁。
   2. 仅以在美国或其他国家（包括你作为居民所在的国家，或你访问和使用注册表所在的国家）适用法律下合法的方式使用注册表、注册表中的 MCP 服务器和注册表数据，且未依据此类法律被禁止访问或使用注册表。你将遵守所有适用的法律、法规和第三方权利（包括但不限于关于数据或软件进出口、隐私、知识产权的法律以及当地法律）。你不会使用注册表、MCP 服务器或注册表数据来鼓励或促进非法活动，或侵犯第三方权利或服务条款。
   3. 通过注册表维护者批准的方法登录，这可能涉及使用第三方拥有的应用或其他软件。

3. 实体使用。如果你代表某个实体访问或使用注册表，你声明并保证你有权使该实体受本条款约束。接受本条款即表示你是代表该实体这样做（且本条款中所有对"你"的提及均指该实体）。

4. 账户信息。为了访问或使用注册表，作为注册流程的一部分，或与你对注册表或其中 MCP 服务器的访问或使用相关，你可能被要求提供某些信息（如身份或联系方式）。你提供的任何信息必须准确且最新，并且你同意及时告知我们任何更新。你理解，为确保质量并核实你对本条款的遵守情况，你对注册表的使用可能受到监测。

5. 反馈。你没有义务提供反馈或建议。如果你就注册表或模型上下文协议提供反馈或建议，那么我们（以及我们许可的人）可以使用此类信息，且对你不承担任何义务。

6. 品牌。仅在能明确表明所指为本注册表、且不暗示关联、背书或赞助的情况下使用"官方 MCP 注册表"这一术语。例如，你可以说"Acme Inc. 通过自动从官方 MCP 注册表拉取数据来保持其数据最新"或"此数据来自官方 MCP 注册表"，但不能说"这是官方 MCP 注册表的网站""我们是查看官方 MCP 注册表数据的首选目的地"或"我们已与官方 MCP 注册表合作以提供此数据"。

7. 修改。我们可能修改本条款或其任何部分，例如以反映法律的变化或模型上下文协议的变化。我们将在本网站或其后继位置发布对本条款修改的通知。如果你不同意修改后的条款，你应停止访问及/或使用注册表。你继续访问及/或使用注册表即构成你对任何修改后条款的接受。

8. 附加条款。视你的预期用例而定，你还必须遵守下方适用的条款。

## 面向 MCP 开发者

9. 禁止事项。通过访问和使用注册表（包括提交 MCP 服务器及/或注册表数据），你同意不：
   1. 分享恶意或有害内容（如恶意软件），即使出于善意或研究目的，也不执行任何意图引入任何病毒、蠕虫、缺陷、木马、恶意软件或任何破坏性质之物的行为；
   2. 诽谤、辱骂、骚扰、跟踪或威胁他人；
   3. 干扰或扰乱注册表或任何相关服务器或网络；
   4. 以意图混淆或误导他人的方式提交数据，包括但不限于通过垃圾内容、发布离题的营销内容、以虚假暗示与第三方存在关联或获其背书的方式发布 MCP 服务器，或以不同名称反复发布相同或相似的 MCP 服务器；
   5. 推广或便利非法在线赌博，或扰乱性的商业信息或广告；
   6. 将注册表用于任何其使用或失效可能导致死亡、人身伤害或环境损害的活动；
   7. 使用注册表处理或存储受美国国务院维护的《国际武器贸易条例》约束的任何数据。

10. 许可。你同意，你提交的关于 MCP 服务器的元数据（例如 schema 名称和描述、URL、标识符）及其他注册表数据旨在公开，并将依据 [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) 奉献至公共领域。提交此类数据即表示你同意你拥有作出此奉献的合法权利（即你拥有这些提交内容的版权，或已获版权所有者许可这样做）并意图这样做。你理解此奉献是永久、不可撤销且全球性的，并在法律允许的最大范围内放弃你可能对贡献享有的任何精神权利。此奉献仅适用于注册表数据，而不适用于你可能指向的第三方注册表中的软件包。

11. 隐私与公开。你理解你发布的任何 MCP 服务器元数据都可能被公开。这包括个人数据，如你的 GitHub 用户名、域名或来自你服务器描述的细节。此外，你理解他人可能会处理你 MCP 服务器元数据中包含的个人信息。例如，子注册表可能通过添加你的 GitHub 仓库有多少 star 来丰富此数据，或对你的代码执行自动化安全扫描。发布服务器即表示你同意他人从事此类处理，并放弃你在某些司法管辖区可能享有的访问、更正、抹除、限制或反对此类处理的权利。
