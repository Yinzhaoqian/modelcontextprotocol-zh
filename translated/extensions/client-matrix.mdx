本矩阵展示了各 MCP 客户端对每个[官方扩展](/extensions/overview)的支持情况。扩展始终是选择启用的：只有当客户端和服务器都在各自[能力](/extensions/overview#negotiation)的 `extensions` 字段中声明支持时，客户端才会使用某个扩展。

<Note>

此列表由社区维护。如果你发现任何不准确之处，或希望添加或更新信息，请[提交一个 pull request](https://github.com/modelcontextprotocol/modelcontextprotocol/pulls)。

</Note>

## 为你的客户端添加扩展支持

如果你正在构建 MCP 客户端并希望实现扩展支持：

1. 查阅扩展规范（例如 [ext-auth](https://github.com/modelcontextprotocol/ext-auth) 或 [ext-apps](https://github.com/modelcontextprotocol/ext-apps) 仓库中的规范）
2. 在客户端于每个请求的 `_meta` 中发送的 `io.modelcontextprotocol/clientCapabilities` 的 `extensions` 字段里声明支持，并从服务器的 [`server/discover`](/specification/draft/server/discover) 响应中读取服务器的 `extensions`
3. 实现该扩展的协议要求
4. 提交一个 pull request 以更新本矩阵

有关能力协商机制的细节，参见[扩展概览](/extensions/overview#negotiation)。
