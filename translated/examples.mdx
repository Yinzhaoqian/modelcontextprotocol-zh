本页展示了各种模型上下文协议（MCP）服务器，它们演示了该协议的能力和多样性。这些服务器使大语言模型（LLM）能够安全地访问工具和数据源。

## 参考实现

这些官方参考服务器演示了 MCP 的核心特性和 SDK 用法：

### 当前的参考服务器

- **[Everything](https://github.com/modelcontextprotocol/servers/tree/main/src/everything)** —— 带有提示、资源和工具的参考／测试服务器
- **[Fetch](https://github.com/modelcontextprotocol/servers/tree/main/src/fetch)** —— 面向高效 LLM 使用的网页内容获取与转换
- **[Filesystem](https://github.com/modelcontextprotocol/servers/tree/main/src/filesystem)** —— 具备可配置访问控制的安全文件操作
- **[Git](https://github.com/modelcontextprotocol/servers/tree/main/src/git)** —— 用于读取、搜索和操作 Git 仓库的工具
- **[Memory](https://github.com/modelcontextprotocol/servers/tree/main/src/memory)** —— 基于知识图谱的持久化记忆系统
- **[Sequential Thinking](https://github.com/modelcontextprotocol/servers/tree/main/src/sequentialthinking)** —— 通过思维序列进行动态、反思式的问题求解
- **[Time](https://github.com/modelcontextprotocol/servers/tree/main/src/time)** —— 时间与时区转换能力

## 开始使用

### 使用参考服务器

基于 TypeScript 的服务器可以直接用 `npx` 使用：

```bash
npx -y @modelcontextprotocol/server-memory
```

基于 Python 的服务器可以用 `uvx`（推荐）或 `pip` 使用：

```bash
# Using uvx
uvx mcp-server-git

# Using pip
pip install mcp-server-git
python -m mcp_server_git
```

### 与 Claude 配合配置

要在 Claude 中使用某个 MCP 服务器，将其添加到你的配置中：

```json
{
  "mcpServers": {
    "memory": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-memory"]
    },
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/path/to/allowed/files"
      ]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "<YOUR_TOKEN>"
      }
    }
  }
}
```
