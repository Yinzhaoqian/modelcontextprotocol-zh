## 群组类型

**工作组**

## 使命陈述

Skills Over MCP 工作组定义"代理技能（agent skills）"——面向代理工作流的丰富、结构化指令——如何通过 MCP 被发现、分发和消费。宿主应用中的原生技能支持展现出强烈需求，本群组源于对 [SEP-2076 —— 将代理技能作为一流 MCP 原语](https://github.com/modelcontextprotocol/modelcontextprotocol/pull/2076)的讨论，该讨论提出了一些开放问题：既有 MCP 原语是否足够，或应标准化哪些约定。本工作组产出规范扩展、参考实现和协调产物，因为解决方案触及协议规范、注册表 schema、SDK 实现和客户端行为。本工作组当前的方向体现在 [SEP-2640 —— Skills 扩展](https://github.com/modelcontextprotocol/modelcontextprotocol/pull/2640)（基于资源，Extensions Track）中。

## 范围

### 范围内

- **规范工作**：定义技能如何在 MCP 内被表示、发现和消费的 SEP——包括 Skills 扩展（Extensions Track）及相关协议变更
- **参考实现**：演示技能发现和消费模式的 SDK 组件和参考服务器
- **跨领域关切**：与 Registry 工作组（技能发现/分发、注册表 schema 变更）、Agents 工作组（技能激活、服务器元数据消费）、Primitive Grouping 工作组（渐进式披露模式）以及外部项目协调，外部项目包括 [Agent Skills](https://agentskills.io/) 规范（内容格式和 well-known URI 发现）、FastMCP 和 PydanticAI
- **文档**：涵盖技能撰写、发现和消费的规范章节及指导

### 范围外

- **注册表 schema 决策**：schema 所有权归 Registry 工作组；本工作组贡献需求，但不拥有该 schema
- **客户端实现强制**：我们可以记录模式，但不能要求特定的客户端行为
- **插件/捆绑包打包**：可安装的捆绑包（技能 + 服务器 + 子代理 + 配置作为单一制品）——由用例揭示，但属于一项更广泛的打包工作

### 相关群组

- **Agents 工作组** —— 代理如何消费服务器元数据、技能激活
- **Registry 工作组** —— 技能发现/分发、注册表 schema 变更
- **Primitive Grouping 工作组** —— 渐进式披露模式
